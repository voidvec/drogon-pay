## 触发与目标

`deploy.yml`（v* tag / workflow_dispatch）：**Docker Hub 镜像 + AWS ECS**（us-east-1，payserver-staging / payserver-production 集群）。staging 随 master、production 随 tag。

```mermaid
flowchart TD
    T[v* tag / dispatch] --> PF[preflight 探测 secrets]
    PF -->|缺失| SKIP[灰跳 不失败]
    PF -->|齐备| TG[tag-gate _tag-gate.yml]
    TG --> BX[Buildx 构建推送 Docker Hub]
    BX --> ST[staging 部署]
    BX --> PR[production: RDS 快照 → 熔断回滚配置 → 部署]
    PR --> HC[/readyz 30 次健康检查]
    HC -->|失败| RB[回滚旧 task-definition]
```

## 关键机制

- **preflight 灰跳**：secrets 缺失时条件化跳过而非红失败（DOCKER_USERNAME/DOCKER_PASSWORD 等是强依赖）；
- **tag-gate 前置**：与 release 共用 `_tag-gate.yml`，未认证 tag 到不了镜像推送与 ECS roll；
- **生产安全网**：先 RDS 快照、熔断回滚配置、/readyz 30 次健康检查、失败回滚旧 task-definition。
