## PR 准入清单

- 三平台 CI 绿（Linux / macOS / Windows）——required；
- 新/改行为有 `DROGON_TEST` 测试覆盖；
- clang-format 干净（`pre-commit run --all-files`）；
- diff 无密钥（gitleaks CI + 本地 pre-commit hook）；
- 架构守卫过（`python scripts/check_architecture.py`）；
- 全部静态门禁本地跑一遍（scripts/check_*.py，stdlib-only）；
- 用户可见变更更新 CHANGELOG `[Unreleased]`；
- 配置键/路由/公共头变更同步文档。

## 提交约定

Conventional Commits：`<type>(<scope>): <imperative subject>`（≤72 字符）。type：feat/fix/refactor/docs/test/build/ci/chore/perf/style；scope 对齐历史（linux/windows/macos/tests/logs/ci-gate/idempotency/alipay/wechat/handlers/services/channels/cmake/pay-admin/docs/agents 等）。破坏性变更：scope 后加 `!` + body 写 `BREAKING:` + 更新 plugin_integration.md 迁移表。

Git 工作流：提交允许，**push 需评审**；调试代码提交前移除（用 LOG_DEBUG）；行尾由 .gitattributes 钉 LF（.bat/.cmd 保持 CRLF）——迁移哈希钉的是字节，CRLF 工作副本会与基线和 Linux runner 不一致。

## 新渠道贡献

多数情况新渠道是**宿主侧插件**（实现 SPI + registerFactory + config 启用），不改库。进库门槛：

- 满足 SPI 契约：线程安全、HttpClient 每 IO loop 复用、verifyCallback 归一化；
- 非对称能力留具体类（不膨胀 SPI）；
- `PayPlugin::registerBuiltinChannels()` 显式注册（禁自注册宏，静态库丢符号）；
- 集成测试齐全，任何测试不得打真实支付端点。

前置阅读：[plugin_integration.md](file://docs/development/plugin_integration.md) 自定义渠道指南与本知识库「渠道SPI与注册中心」页。
