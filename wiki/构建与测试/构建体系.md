## Conan 2 打包策略

- 包类型 **static-library**；唯一发布物 `libs/drogon-pay/`（exports_sources 排除 examples/tests）；
- Drogon **1.9.13 钉死**：静态库 + C++ ABI 决定库与宿主必须同版；OpenSSL 3.5.7 / jsoncpp 1.9.5 force 覆盖；
- toolchain 路径由 conanfile layout 钉住；lockfile 需显式指定 build profile 以包含 build_requires（Linux/macOS CI 曾因此报错）。

**Sources** · [conanfile.py](file://conanfile.py)

## 七个 CMake preset

| preset | 平台/配置 |
|--------|-----------|
| linux-release / linux-debug | Linux 单配置 |
| linux-coverage | Linux gcov（仅 gcc） |
| windows-msvc / windows-msvc-debug | Windows 多配置（binaries 在 …/Release\|Debug） |
| macos-arm64 / macos-debug | macOS arm64（conan 加 -s arch=armv8） |

CMake 开关：`DROGON_PAY_BUILD_EXAMPLES` / `DROGON_PAY_BUILD_TESTS`（默认 ON，PAY_BUILD_TESTS/BUILD_TESTS 是 CI 兼容别名）、`DROGON_PAY_WERROR`（CI 传 ON）、`DROGON_PAY_COVERAGE`。

## 孪生入口脚本

build / test / setup_database / deploy / check_config 各有 .sh/.bat，**逐参数对齐**：conan install → cmake --preset → cmake --build --preset → 拷贝 config.json/.env/certs 到二进制旁。`scripts/check_docs_drift.py` R7 守护孪生集完整性（.sh 必须在 git index 里可执行；单平台脚本必须声明理由）。e2e 刻意是 bash + PowerShell。

## 消费者验证链（test_package）

`test_package/` 仅 3 个源文件：`conan create` 时以最小 Drogon 宿主 find_package 链库 → 内存 sqlite3（无外部依赖）→ 加载 PayPlugin → 断言 `getPlugin<PayPlugin>()` 非空（DrObject 注册符号未被静态链接丢弃）→ GET `/api/pay/query` 非 404（401 即证明处理链已接通）→ 干净退出。`_sdk-smoke.yml` 还 grep 日志强制出现 `[test_package] OK`，防 can_run 跳过造成假绿。

```mermaid
flowchart LR
    A[conan create] --> B[test_package 最小宿主]
    B --> C[find_package DrogonPay]
    C --> D[加载 PayPlugin 断言非空]
    D --> E[GET query 非 404]
    E --> F[grep 日志 test_package OK]
```
